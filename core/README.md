## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se compilan con `valac`. Los proyectos tipo librería separan `src/` y `test/`, y usan GLib.Test con `Test.add_func`, `assert` y `Test.run`.

**EN:** Standalone scripts are compiled with `valac`. Library-style projects separate `src/` and `test/`, and use GLib.Test with `Test.add_func`, `assert`, and `Test.run`.
