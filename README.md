# Vala

Proyectos en **Vala**, con programas independientes compilados mediante `valac` y proyectos tipo librería probados con **GLib.Test**, el framework de pruebas integrado en el entorno GLib.

---

## 📂 Módulos / Modules

| Módulo | Descripción |
| ------ | ----------- |
| [`core/foundations/`](core/foundations/) | **Fase 0 — Fundamentos**: `helloworld`, `hellouser`, `unit_test/calculator`, `numbers` |
| [`core/algorithms/`](core/algorithms/) | **Fase 1 — Algoritmos Puros**: `naive_sort` |

---

## ▶️ Comenzar / Getting Started

```bash
# Verificar el toolchain
valac --version
pkg-config --modversion glib-2.0 gobject-2.0

# Hello, World!
cd core/foundations/helloworld
valac helloworld.vala -o /tmp/vala-helloworld
/tmp/vala-helloworld

# Hello, User!
cd ../hellouser
valac HelloUser.vala -o /tmp/vala-hellouser
printf 'Ada\n' | /tmp/vala-hellouser

# Calculator tests
cd ../unit_test/calculator
valac src/calculator.vala test/calculator_test.vala --pkg glib-2.0 -o /tmp/vala-calculator-test
/tmp/vala-calculator-test

# Numbers tests
cd ../../numbers
valac src/numbers.vala test/recursive_tests.vala --pkg glib-2.0 -o /tmp/vala-numbers-recursive-tests
/tmp/vala-numbers-recursive-tests
valac src/numbers.vala test/iterative_tests.vala --pkg glib-2.0 -o /tmp/vala-numbers-iterative-tests
/tmp/vala-numbers-iterative-tests

# Naive Sort tests
cd ../../algorithms/naive_sort
valac src/naive_sort.vala test/naive_sort_tests.vala --pkg glib-2.0 -o /tmp/vala-naive-sort-tests
/tmp/vala-naive-sort-tests
```

## 🏗️ Tipos de proyecto / Project Types

### 1. Programa independiente (`valac`)

**ES:** `helloworld` y `hellouser` son archivos `.vala` compilados directamente a ejecutables nativos mediante `valac`.

**EN:** `helloworld` and `hellouser` are `.vala` files compiled directly into native executables through `valac`.

```bash
valac <File>.vala -o <binary>
./<binary>
```

### 2. Proyecto tipo librería con GLib.Test

**ES:** `calculator` y `numbers` separan `src/` y `test/`. `valac` compila el módulo junto con la suite, y GLib.Test registra y ejecuta los casos mediante `Test.add_func` y `Test.run`.

**EN:** `calculator` and `numbers` separate `src/` and `test/`. `valac` compiles the module together with the suite, and GLib.Test registers and runs cases through `Test.add_func` and `Test.run`.

## 🔁 Decisión de TCO / TCO Decision

Vala tiene iteración nativa mediante `for` y `while`, pero no ofrece una garantía general de Tail Call Optimization. Por eso `numbers` conserva `_acc` como puente educativo sin suite propia y prueba `_rec` e `_ite`:

Vala has native iteration through `for` and `while`, but does not provide a general Tail Call Optimization guarantee. Therefore `numbers` keeps `_acc` as an educational bridge without a dedicated suite and tests `_rec` and `_ite`:

```text
TCO no garantizada + iteración nativa ✅
_rec + _ite
2 suites
10 tests
22 casos
```

---

## 🧪 Convenciones de pruebas / Testing Conventions

**ES:** GLib.Test está incluido en el entorno GLib. Las suites se registran con `Test.add_func`, usan `assert` y finalizan con `Test.run`. `calculator` tiene 5 tests; `numbers` tiene 10 tests y 22 casos/assertions.

**EN:** GLib.Test is included in the GLib environment. Suites register tests with `Test.add_func`, use `assert`, and finish with `Test.run`. `calculator` has 5 tests; `numbers` has 10 tests and 22 cases/assertions.

Local `.gitignore` files exclude executables, generated C code, objects, libraries, and Vala files generated by `valac`. Quick-start commands write binaries under `/tmp`.
